❔ Ayuda

Gracias por jugar este juego, el mismo consiste en una aventura de plataformas retro en 2D donde pondrás a prueba tus conocimientos matemáticos para superar tres niveles (Grecia, Ciudad y Desierto). Tu objetivo es alcanzar la meta de cada escenario antes de que el contador de 3 minutos llegue a cero, administrando cuidadosamente tus 3 vidas iniciales.

Se juega utilizando los controles de movimiento para desplazarte (izquierda, derecha) y saltar por el relieve del mapa. Si chocas con un obstáculo fijo o móvil, el avance se detendrá y deberás responder correctamente a una pregunta de geometría o trigonometría para que se te permita el paso; si contestas de forma incorrecta, perderás una vida. También puedes saltar para golpear los cuadros flotantes de habilidad desde abajo y resolver retos opcionales, los cuales te recompensarán con ventajas estratégicas como inmunidad temporal, tiempo extra o vidas adicionales.
